# 坦克大战 · Tank Battle

一个用纯 HTML5 Canvas 编写的经典坦克大战游戏，无需任何依赖，打开 `index.html` 即可游玩。

## 玩法

- 控制你的坦克，消灭所有敌方坦克，并保护基地（底部老鹰图标）不被摧毁。
- 每关共 8 辆敌军坦克，全部消灭后进入下一关。
- 地形包含可摧毁的砖墙、不可摧毁的钢墙、阻挡坦克的水域，以及可以藏身的树林。

## 操作

| 按键 | 功能 |
| --- | --- |
| `W` / `A` / `S` / `D` 或方向键 | 移动 |
| `空格` / `J` / `回车` | 发射 |
| `P` | 暂停 / 继续 |

移动端支持触屏滑动移动、点击发射。

## 运行

直接用浏览器打开 `index.html`，或通过 GitHub Pages 在线游玩。

## 技术

- 纯原生 JavaScript + Canvas 2D，零依赖。
- 实体碰撞检测、敌人 AI、粒子特效、关卡随机生成。
